# Известные ограничения проекта в целом

Ограничения бэкенда — `BACKEND_KNOWN_ISSUES.md`, фронтенда — `FRONTEND_KNOWN_ISSUES.md`. Здесь — то, что связано со сборкой и интеграцией.

## Критично
1. **Ничего не компилировалось в Unity.** Проект проверен только чтением и скриптами. Первая сборка в GitHub Actions — первая настоящая проверка.
2. **Нужна лицензия Unity** (бесплатный Personal подходит) и три секрета GitHub. Схема активации GameCI может измениться — ориентируйтесь на https://game.ci/docs/github/activation.
3. **Версия Unity и Docker-образ.** Образ для версии из `ProjectVersion.txt` должен существовать у GameCI; при ошибке смените версию 2022.3.x.

## Сборка и платформа
4. APK подписан отладочным ключом (годится для установки вручную; для Google Play нужен свой keystore и AAB).
5. Только ARM64 по умолчанию (быстрее и меньше). 32-битные телефоны — запуск вручную с галочкой ARMv7.
6. Сцена и `.meta`-файлы в репозиторий не входят: сцена создаётся при каждой сборке, `.meta` Unity создаёт сам.
7. Первая сборка занимает 30–60 минут, повторные — быстрее благодаря кэшу `Library`.
8. Релизы копятся (`build-1`, `build-2`, …); устаревшие можно удалять вручную.

## Игра
9. Графика прототипная (круги, квадраты, сетка); звука нет; частиц нет.
10. Враги ходят по прямой без поиска пути; в комнатах стоят простые блоки, враги могут застревать.
11. Баланс не проверялся играбельностью.
12. Маршрут комнат линейный (3/5/4 комнаты), ветвления нет.
13. Шрифт строится при запуске из TTF (Liberation Sans): первые кадры после запуска могут иметь небольшую задержку при создании атласа.
14. Игрок и враги не сталкиваются физически (слои 8 и 9 игнорируются): урон от врагов идёт по дистанции.
