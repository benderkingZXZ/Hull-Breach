# Известные ограничения и нерешённые проблемы

## Критично
1. **Код не компилировался и не тестировался в Unity** (нет окружения). Возможны ошибки компиляции и ошибки настройки; EditMode-тесты не запускались.
2. **Нет префабов, сцены и арта.** Комплект — только код и документация; префабы комнат/врагов создаются по README.

## Геймплей
3. **Нет навигации врагов.** Движение — по прямой к игроку (`Rigidbody2D.MovePosition`). Враги могут «застревать» на стенах; шаблоны комнат лучше делать открытыми, с малым числом препятствий. Решение при необходимости: A* / NavMeshPlus.
4. **Маршрут линейный.** Комнаты: цепочка 0→1→…→N−1 (вход → … → реактор). Тупики и ветвления намеренно не генерируются (гарантия связности), вариативность — за счёт выбора шаблонов. Ветвление не реализовано.
5. **Корабль-босс** использует те же 3 точки входа и наборы шаблонов; его отличия — множитель сложности 2.2 и мини-босс (в концепции особого описания нет). При желании добавить отдельный набор комнат.
6. **Мини-босс** — один тип (ближний бой + круговой залп). Модель «фаз» не реализована.
7. **Комната реактора**: «уничтожение реактора» = победа над мини-боссом; интерактивного реактора нет (визуал — через `UnityEvent reactorDestroyed`).
8. **Модули:** один экземпляр каждого модуля за забег, не более 4 за забег (по числу кораблей); дубликаты/улучшение редкости не реализованы. Активные модули срабатывают одновременно с навыком робота (решение зафиксировано в API.md, п. 6).
9. **Здоровье** по умолчанию восстанавливается полностью на каждом корабле (`restoreHealthOnShipStart`, переключается).
10. **Награды врагов** начисляются сразу в кошелёк (подбираемых предметов нет); при смерти они сохраняются, как требует концепция.
11. Смерть = сброс всего забега (корабли и модули); ресурсы и улучшения остаются.

## Технические
12. Снаряды и враги создаются через `Instantiate/Destroy` (нет пулинга) — для прототипа допустимо, на слабых Android возможны микрофризы при большом числе снарядов.
13. Незавершённый забег **не сохраняется** (сохраняется только мета-прогресс). Выход из игры = прерванный забег.
14. Нет паузы (`Time.timeScale` не трогается), нет звука, нет камеры, нет локализации (русские строки зашиты в каталогах данных).
15. `TargetRegistry` — статический; при выключенном Domain Reload сбрасывается через `RuntimeInitializeOnLoadMethod`.
16. Сохранение: JsonUtility + `.bak`; шифрования и защиты от читерства нет; облачных сохранений нет.
17. Ввод с клавиатуры (отладка) работает только при включённом Legacy Input Manager.
18. Баланс не проверялся играбельностью — числа ориентировочные.
19. Комнаты размещаются на одной линии с шагом `roomSpacing`; если шаблон больше шага, комнаты пересекутся (неактивные комнаты отключены, но стоит держать запас).
20. Физика врагов: динамические тела могут толкать друг друга/игрока; при необходимости настроить Layer Collision Matrix.
